## 🛰️ Featured Projects

### [Horizons Asteroid Search](https://github.com/Tailspin45/horizons-asteroid-search) 🪨
TypeScript program to search for asteroids using NASA JPL Horizons and Asterank APIs
- Query specific asteroids by name or ID
- Find Near-Earth Asteroids (NEAs) and potentially hazardous asteroids (PHAs)
- Get orbital elements and ephemeris data
- Detect close approaches to Earth
- **Tech:** TypeScript, NASA JPL Horizons API

### [Flymoon](https://github.com/Tailspin45/flymoon-main) ✈️🌙
Aircraft sun/moon transit predictions - catch planes crossing the Moon or Sun!
- Real-time flight tracking with transit predictions
- Web app for local LAN network deployment
- Calculates intersections between aircraft flight paths and celestial bodies
- Auto-check mode with push notifications for likely transits
- **Tech:** Python, FlightAware AeroAPI, Web-based interface

### [Skills Copilot Codespaces](https://github.com/Tailspin45/skills-copilot-codespaces-vscode) 🤖
Learning repository for mastering GitHub Copilot in VS Code and Codespaces
- Hands-on practice with AI-powered code suggestions
- Development environment configuration examples
- **Tech:** GitHub Copilot, VS Code, Codespaces
